## About

**axis.dk** is a personal engineering platform dedicated to infrastructure architecture, automation, platform engineering, and continuous learning.

It provides a practical environment for designing, deploying, documenting, and operating modern infrastructure using industry best practices.

Rather than focusing on individual technologies, **axis.dk** focuses on building reliable, maintainable, and scalable systems.
